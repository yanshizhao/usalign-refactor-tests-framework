五、Usalign-beta 分支功能提交总结（2026-05-23）
---------------------------------------------

Usalign-beta 分支共 3 个提交，全部修改 USalign.cpp，总计 63 行新增、4 行删除。

提交列表：

1. 3e5d73d Phase 1: -dir1 + -mm 1 support for oligomeric batch alignment
   - 支持 -dir1 与 -mm 1 组合使用
   - 实现“目录中每个复合物 vs 指定目标”的寡聚体批量比对
   - 通过遍历 chain1_list，逐个构造单元素输入列表并调用 MMalign()

2. ef648bf Phase 2: -dir2 + -mm 1 support for oligomeric batch alignment
   - 支持 -dir2 与 -mm 1 组合使用
   - 实现“指定查询 vs 目录中每个复合物”的寡聚体批量比对
   - 通过遍历 chain2_list，逐个构造单元素输入列表并调用 MMalign()

3. 42cc64f Phase 3: -dir + -mm 1 support for oligomeric all-vs-all alignment
   - 支持 -dir 与 -mm 1 组合使用
   - 实现目录内寡聚体全对全比对
   - 使用上三角二重循环 ii < jj，避免重复比对和自比对

核心功能变化：

1. 解除 -mm 1 与 -dir/-dir1/-dir2 的不兼容限制
   - 原版会禁止 -mm 1 或 -mm 2 与 -dir 同时使用
   - beta 分支改为仅禁止 -mm 2 与 -dir 同时使用
   - -mm 1 寡聚体比对现在可以进入批量处理逻辑

2. 新增 -mm 1 批量模式调度逻辑
   - -dir1：目录查询集逐个比对到固定目标
   - -dir2：固定查询逐个比对到目录目标集
   - -dir：目录内结构两两全对全比对
   - 每个批量组合最终仍复用既有 MMalign() 主逻辑

3. 新增 -chainmap 互斥检查
   - -chainmap 仍只允许与 -mm 1 使用
   - beta 分支进一步禁止 -chainmap 与 -dir、-dir1、-dir2 同时使用
   - 原因是批量模式下每一对复合物可能需要不同链映射，单个 chainmap 文件不适合全局复用

总体结论：

Usalign-beta 分支的主要功能是让寡聚体比对模式（-mm 1）支持批量输入，包括 -dir1、-dir2 和 -dir 三类目录模式。实现方式较保守，没有改动 MMalign() 核心算法，而是在 main() 的调度层增加循环，将批量任务拆成多个单对寡聚体比对执行。
