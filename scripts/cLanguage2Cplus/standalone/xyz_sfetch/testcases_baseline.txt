# xyz_sfetch standalone program test cases (baseline, master branch)
# Baseline runs on master, which has no -outdir option; run_test.py appends
# "-outdir ." to cases that do not already specify one.
# Format: <name> <working_dir> <arguments...>
# <working_dir> is relative to the data/ directory
#
# Cases run in file order and share state: the index-building case must come
# before the fetching cases, and the missing-index case must come first.
#
# Covers: index building (stdout listing + .index file), fetching one/multiple
# entries, fetching a name that is not in the index, fetching without an index,
# and writing/reading the index through a non-default -outdir.
