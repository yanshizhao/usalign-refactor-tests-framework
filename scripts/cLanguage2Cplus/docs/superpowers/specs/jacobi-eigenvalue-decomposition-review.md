# 雅可比（Jacobi）特征值分解回顾

> 记录日期：2026-06-17
> 涉及文件：`USalign/Kabsch.h`
> 背景：USalign C→C++ 重构中，将 Kabsch 算法的 SVD 部分从解析法（三次方程）替换为循环雅可比迭代法

---

## 一、问题概述

将 Kabsch 算法中 3×3 对称矩阵的特征值分解从**解析法**（求解三次特征方程的特征多项式）替换为**循环雅可比迭代法**（cyclic Jacobi）后，14 个回归测试中有 11 个失败。失败原因包括：

- 比对路径完全改变
- 链分配方案改变
- TM-score 系统性下降 5~11%
- 叠合结构坐标完全不同

**根因**：雅可比迭代法产生的特征向量矩阵中，排序操作导致行列式符号翻转，最终旋转矩阵变成了反射矩阵。

---

## 二、数学背景

### 2.1 Kabsch 算法

Kabsch 算法计算两组点之间的最优旋转矩阵。给定两组对应点集 $\\{x_i\\}$ 和 $\\{y_i\\}$（已去质心），协方差矩阵：

$$r_{ij} = \sum_k x_{ki} \cdot y_{kj}$$

最优旋转矩阵通过奇异值分解（SVD）得到：

$$r = U \cdot \Sigma \cdot V^T$$

$$R_{\text{opt}} = U \cdot V^T$$

为了保证 $\det(R) = +1$（正当旋转非反射），需要对 $\det(r) < 0$ 的情况做特殊处理。

### 2.2 对称矩阵的特征值分解

对于 3×3 对称矩阵 $M = r^T r$，其特征值分解等价于 $r$ 的右奇异向量：

$$M \cdot v_i = \lambda_i \cdot v_i$$

其中 $\lambda_i = \sigma_i^2$ 是 $r$ 的奇异值的平方。

### 2.3 雅可比方法

雅可比方法通过一系列**吉文斯旋转（Givens rotation）**将对角化矩阵。每次选择一个非对角元 $(p, q)$ 消去：

$$
J(p,q,\theta) = \begin{pmatrix}
1 & & & & \\
& c & \cdots & -s & \\
& \vdots & \ddots & \vdots & \\
& s & \cdots & c & \\
& & & & 1
\end{pmatrix}, \quad c = \cos\theta,\; s = \sin\theta
$$

更新规则：
1. $A \leftarrow J^T A J$ — 消去 $A[p][q]$
2. $V \leftarrow V J$ — 累积特征向量

### 2.4 吉文斯旋转的行列式

$$\det(J) = c^2 + s^2 = \cos^2\theta + \sin^2\theta = +1$$

因此右乘吉文斯旋转不改变特征向量矩阵的行列式。

### 3.1 `jacobi_rotate_step` — 单步旋转（第 6-51 行）

```cpp
static inline void jacobi_rotate_step(RotMat& A, RotMat* eig_vecs,
                                      int p, int q, double epsilon);
```

**功能**：对对称矩阵 $A$ 做一次吉文斯旋转，消去 $A[p][q]$ 和 $A[q][p]$。

**旋转角度计算**（symSchur2 稳定公式）：

```cpp
const double tau = (aqq - app) / (2.0 * apq);
if (tau >= 0.0)
    t = 1.0 / (tau + sqrt(1 + tau²));
else
    t = 1.0 / (tau - sqrt(1 + tau²));

c = 1 / sqrt(1 + t²)
s = t * c
```

保证 $|\theta| \leq \pi/4$，数值稳定。

**矩阵更新**（采用 $J = \begin{pmatrix}c & s \\ -s & c\end{pmatrix}$ 约定，即旋转 $-\theta$）：

```cpp
A[p][p] = c²·app - 2cs·apq + s²·aqq
A[q][q] = s²·app + 2cs·apq + c²·aqq
A[p][q] = A[q][p] = 0

// 剩余行（r ≠ p,q）
A[r][p] = c·mrp - s·mrq
A[r][q] = s·mrp + c·mrq
```

**特征向量更新**（$V \leftarrow V \cdot J$）：

```cpp
V'[i][p] = c·V[i][p] - s·V[i][q]
V'[i][q] = s·V[i][p] + c·V[i][q]
```

### 3.2 `jacobi_eigen3` — 3×3 循环雅可比（第 58-93 行）

```cpp
inline bool jacobi_eigen3(const RotMat& M, array<double,3>& eig_vals,
                          RotMat* eig_vecs = nullptr,
                          double epsilon = 1e-12, int max_sweeps = 10);
```

**算法**：

```
1. A = M（拷贝输入矩阵）
2. V = I（特征向量初始化为单位阵）
3. 对每次扫描 (sweep = 0..max_sweeps-1):
   a. 计算对角元总和 diag_norm = |A[0][0]| + |A[1][1]| + |A[2][2]|
      * 如果 diag_norm ≤ epsilon，矩阵已退化，提前退出
      * 如果非对角元总和 < epsilon × diag_norm（相对精度达标），提前退出
   b. 依次消去 (0,1), (0,2), (1,2)
4. 提取对角元作为特征值
```

**收敛判据**：使用**相对阈值** `epsilon = 1e-12`，即 `off_diag < epsilon × diag_norm`。对于元素量级 $10^8$~$10^{12}$ 的 Gram 矩阵，等效绝对阈值为 $10^{-4}$~$10^{0}$，在双精度浮点可达到范围内，因此**通常 3~6 轮即可提前收敛**，无需跑满 10 轮。

### 3.3 `Kabsch` — 主函数（第 112-342 行）

**数据流**：

```
输入 x, y (CoordArray)
  ↓
模块1: 初始化
  ↓
模块2: 计算质心 xc, yc 和协方差矩阵 r
  ↓
模块3: 计算 det(r) → sigma（用于反射修正）
  ↓
模块4: M = r^T * r（Gram 矩阵）
  ↓
模块5: jacobi_eigen3(M, e, &a) → 特征值 e, 特征向量 a = V
  ↓
模块6: 特征值降序排序，同步交换 a 的列 —— 此处有逻辑错误 ❌
  ↓
模块7: b = r * a（左奇异向量），Gram-Schmidt 正交化，叉乘第三列
        u = b * a^T（最优旋转矩阵）
  ↓
模块8: t = yc - u * xc（平移向量）
  ↓
模块9: rms = e0 - 2*sum(sigma_i)（残差计算）
```

## 四、核心逻辑错误

### 4.1 错误位置

**第 214-224 行**：特征值排序 + 特征向量列交换

```cpp
for (i = 0; i < 2; ++i) {
    for (j = i+1; j < 3; ++j) {
        if (e[i] < e[j]) {
            std::swap(e[i], e[j]);
            if (mode != 0) {
                for (k = 0; k < 3; ++k)
                    std::swap(a[k][i], a[k][j]);  // ← 交换列
            }
        }
    }
}
```

### 4.2 错误链

**步骤 1**：雅可比算法产生 $\det(V) = +1$

```
V₀ = I, det(V₀) = +1
V₁ = V₀ · J₁, det(V₁) = det(V₀) · det(J₁) = +1 · +1 = +1
...
Vₙ = V₀ · J₁ · J₂ · ... · Jₙ, det(Vₙ) = +1
```

**步骤 2**：排序时交换两列翻转行列式符号

对于 3×3 矩阵，交换列 $i$ 和 $j$：

$$\det(V') = -\det(V)$$

特征值的 6 种初始排列需要的交换次数奇偶性：

| Jaco输出顺序 | 交换次数 | 奇偶 | det(V) |
|---|---|---|---|
| [大, 中, 小] | 0 | 偶 | +1 ✅ |
| [大, 小, 中] | 2 | 偶 | +1 ✅ |
| [中, 大, 小] | 1 | 奇 | -1 ❌ |
| [中, 小, 大] | 3 | 奇 | -1 ❌ |
| [小, 大, 中] | 2 | 偶 | +1 ✅ |
| [小, 中, 大] | 1 | 奇 | -1 ❌ |

约一半情况下 $\det(V) = -1$。

**步骤 3**：$\det(V) = -1$ 导致旋转矩阵变成反射

左奇异向量矩阵 $B$ 的第 3 列由叉乘得到（第 300-302 行），保证 $\det(B) = +1$：

```cpp
b[:,2] = b[:,0] × b[:,1]
```

旋转矩阵 $U = B \cdot V^T$，其行列式为：

$$\det(U) = \det(B) \cdot \det(V^T) = (+1) \cdot \det(V)$$

$$\therefore \det(U) = \det(V)$$

当 $\det(V) = -1$ 时，$\det(U) = -1$，**$U$ 是反射矩阵而非旋转矩阵**。

### 4.3 原始代码为什么没有这个问题

原始算法（解析法）使用了不同的特征向量构造方式：

1. 通过三次方程解析解得到特征值，已经是降序排列
2. 只计算第 0 列和第 2 列的特征向量（用伴随矩阵 adjugate）
3. **第 1 列由叉乘得到**：

```c
a[:,1] = cross(a[:,2], a[:,0])
```

对于右手正交基 $\\{v_0, v_1, v_2\\}$ 恒有：

$$v_2 \times v_0 = v_1$$

这保证了 $\det(V) = +1$，不需要排序。

## 五、修复

### 5.1 修复代码

在第 224 行排序之后、第 238 行旋转矩阵计算之前，插入行列式校正：

```cpp
// 第 226-235 行
if (mode != 0) {
    double det_a = a[0][0]*(a[1][1]*a[2][2] - a[1][2]*a[2][1])
                 - a[0][1]*(a[1][0]*a[2][2] - a[1][2]*a[2][0])
                 + a[0][2]*(a[1][0]*a[2][1] - a[1][1]*a[2][0]);
    if (det_a < 0.0) {
        for (k = 0; k < 3; ++k)
            a[k][2] = -a[k][2];  // 翻转第三列（对应最小奇异值）
    }
}
```

### 5.2 数学原理

翻转第三列等价于将最小奇异值的符号取反，这是 Kabsch 算法中处理反射的标准做法。Kabsch 原文（Acta Cryst. 1976）中明确指出：当 $\det(r) < 0$ 时，应将最小奇异值对应的右奇异向量取反。

## 六、数值精度分析

### 6.1 收敛性

`jacobi_eigen3` 的收敛判据使用**相对阈值** `epsilon = 1e-12`，即 `off_diag < epsilon × diag_norm`。对于元素量级 $10^8$ 至 $10^{12}$ 的 Gram 矩阵 $M = r^T r$，等效绝对阈值约为 $10^{-4}$ 至 $10^{0}$，在双精度浮点可达到范围内。因此：

- 收敛条件通常在第 3~6 轮触发
- 不再跑满 10 轮扫描
- 对 3×3 矩阵收敛到机器精度

### 6.2 与解析法的比较

| 方面 | 解析法（原始） | 雅可比法（新） |
|------|-------------|--------------|
| 精度 | 机器精度（非迭代） | 机器精度（~6 轮迭代） |
| 数值稳定性 | 对近退化矩阵可能不稳定 | 更稳定 |
| 速度 | 快（常数量级） | 略慢（10×3 次旋转） |
| 可移植性 | 仅 3×3 | 可推广到 n×n |
| 特征向量排序 | 固有降序 | 需要额外排序 |

### 6.3 残留差异

修复后剩余的 3/14 测试失败全部属于以下类型：

**类型 A：$(-0.0)$ vs $(+0.0)$**
- 单位矩阵中零的符号差异
- 来自不同路径的浮点求和顺序不同
- 对数学结果完全无影响

**类型 B：末位 1 ulp 差异**
- 如 `193.6890484356` vs `193.6890484355`
- 来自雅可比旋转角度与解析法角度的微小差异
- 差异量级 $10^{-10}$，在双精度正常误差范围内

**类型 C：平局决胜**
- MSTA 多结构比对中，链 B 与两个不同参考链的 TM-score 完全相同（`0.5084`）
- 原始法与雅可比法因数值路径不同选择了不同的参考链
- 统计学上等价

## 九、附录：直观的 ASCII 图形补充解释

### 9.1 吉文斯旋转矩阵 J（消去 (p,q)=(0,1)）

```
         列0       列1     列2
    ┌──────────────────────────────┐
行0 │  cosθ      -sinθ      0      │
行1 │  sinθ       cosθ      0      │
行2 │   0         0         1      │
    └──────────────────────────────┘

行列式计算：
    det(J) = cosθ × (cosθ × 1 - 0 × 0)
           - (-sinθ) × (sinθ × 1 - 0 × 0)
           + 0 × (sinθ × 0 - cosθ × 0)

           = cosθ × cosθ + sinθ × sinθ
           = cos²θ + sin²θ
           = 1    ← 每次右乘 J，行列式不变
```

### 9.2 初始 V₀ = I（det = +1）

```
        列0   列1   列2
    ┌────────────────────┐
行0 │  1     0     0     │
行1 │  0     1     0     │
行2 │  0     0     1     │
    └────────────────────┘

    det(V₀) = 1
```

### 9.3 交换两列 → 行列式符号翻转

用 2×2 举个直观例子：

```
原始矩阵：                    交换两列后：
    ┌        ┐                   ┌        ┐
    │ 1    4 │                   │ 4    1 │
    │ 2    5 │                   │ 5    2 │
    └        ┘                   └        ┘

det = 1×5 - 2×4 = -3       det = 4×2 - 5×1 = +3

符号翻转了！ -3 → +3
```

对 3×3 矩阵也是一样：

```
交换列0和列1：
    ┌             ┐          ┌             ┐
    │ a    b    c │          │ b    a    c │
V = │ d    e    f │    V' =  │ e    d    f │
    │ g    h    i │          │ h    g    i │
    └             ┘          └             ┘

det(V') = -det(V)    ← 每次交换都翻转一次符号
```

```
                        │
                        ▼
               排序 → 交换列 → 行列式翻转
                        │
                   ┌────┴────┐
                   ▼         ▼
           交换偶数次     交换奇数次
          det(V) = +1    det(V) = -1  ❌
              ✅           (50%概率)
                            │
                            ▼
            U = B · V^T
            det(U) = det(B) × det(V)
                   = (+1) × (-1)
                   = -1
                            │
                            ▼
                    U 是反射矩阵！
                  （不是旋转矩阵）
                            │
                            ▼
            蛋白质被镜像 → 坐标全错
                            │
                            ▼
            TM-score 下降 5~11%
            比对路径改变
            链分配改变
            11/14 测试失败
```

### 9.7 数值例子：排序前后 det(V) 的变化

假设雅可比输出的 V（未排序）：

```
特征值 e = [4, 9, 1]    ← 未排序

特征向量矩阵 V 的每一列是对应的特征向量：
        列0(v₀)  列1(v₁)  列2(v₂)
    ┌─────────────────────────────┐
行0 │   0.6     -0.8      0.0     │
行1 │   0.8      0.6      0.0     │
行2 │   0.0      0.0      1.0     │
    └─────────────────────────────┘

det(V) = 0.6 × (0.6×1.0 - 0×0) - (-0.8) × (0.8×1.0 - 0×0) + 0
       = 0.36 + 0.64
       = 1.0    ✅
```

排序（i=0, j=1: e[0]=4 < e[1]=9 → 交换列0↔列1）：

```
排序后：
        列0(v₁)  列1(v₀)  列2(v₂)
    ┌─────────────────────────────┐
行0 │  -0.8      0.6      0.0     │
行1 │   0.6      0.8      0.0     │
行2 │   0.0      0.0      1.0     │
    └─────────────────────────────┘

det(V') = (-0.8) × (0.8×1.0 - 0×0) - 0.6 × (0.6×1.0 - 0×0) + 0
        = -0.64 - 0.36
        = -1.0    ❌  行列式翻转了！
```

继续追踪到旋转矩阵 U：

```
B 的行列式：    det(B) = +1    (叉乘构造第三列保证右手正交系)

U = B · V'^T

det(U) = det(B) × det(V'^T)
       = det(B) × det(V')
       = (+1) × (-1)
       = -1     ❌  U 是反射矩阵！
```

### 9.8 核心因果链总结

**一句话精炼：**

> **排序操作在调整特征值顺序时，无意识地翻转了特征向量矩阵的定向，而 Kabsch 算法要求定向始终为右手系（$\det=+1$），翻转后旋转矩阵退化为反射矩阵。**

**逐步因果链：**

```
雅可比算法计算出来的特征值的大小顺序是不一定的
    → 特征向量矩阵与特征值是对应的
    → 对特征值降序排序时，必须同步交换特征向量矩阵的列
    → 交换列会翻转行列式的符号（每次交换 det 乘以 -1）
    → 6 种初始排列中 3 种需要奇数次交换 → 50% 概率 det(V) = -1
    → det(U) = det(B) × det(V^T) = (+1) × det(V) = det(V)
    → det(V) = -1 ⇒ det(U) = -1 ⇒ U 是反射矩阵而非旋转矩阵
    → 蛋白质被镜像 → TM-score 下降、比对路径改变、链分配改变
```

这也解释了为什么原始解析法没有这个问题——解析法通过三次方程算出的特征值天然就是降序的，**根本不需要排序**，自然也就没有列交换、没有行列式翻转。且原始法的第 1 列由叉乘 $v_1 = v_2 \times v_0$ 得到，自动保证右手正交系。
