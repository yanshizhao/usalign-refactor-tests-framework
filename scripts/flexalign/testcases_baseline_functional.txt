# Functional regression test cases for -mm 7 (flexible alignment)
# Format: <name> <workdir> <arg1> <arg2> ...
# workdir: relative to data/ directory (i.e., data/<pair_name>/)
# -mm 7: flexible alignment mode
# -afp: AFP-enhancement mode (uses flexalign_usbcat instead of flexalign_greedy)
# -outfmt -1: output format that includes version info for deterministic comparison
# -m -: output rotation matrix to stdout (captured in baseline)

# 1. Low TM-score baseline tests (structure quite different)
# ==============================================================================

flex_low_afp_4i0k_2x1xR      4i0kA-2x1xR   4i0kA.pdb 2x1xR.pdb -afp -mm 7 -outfmt -1 -m -
