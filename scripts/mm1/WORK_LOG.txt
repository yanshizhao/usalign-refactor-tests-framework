V. Usalign-beta Branch Feature Commit Summary (2026-05-23)
---------------------------------------------

Usalign-beta branch has 3 commits, all modifying USalign.cpp, totaling 63 lines added, 1 line deleted.
Commit list:
1. 3e5d73d Phase 1: -dir1 + -mm 1 support for oligomeric batch alignment
   - Supports combined use of -dir1 with -mm 1
   - Implements "each complex in directory vs specified target" oligomer batch alignment
   - Iterates chain1_list, constructs single-element input lists and calls MMalign() individually

2. ef648bf Phase 2: -dir2 + -mm 1 support for oligomeric batch alignment
   - Supports combined use of -dir2 with -mm 1
   - Implements "specified query vs each complex in directory" oligomer batch alignment
   - Iterates chain2_list, constructs single-element input lists and calls MMalign() individually

3. 42cc64f Phase 3: -dir + -mm 1 support for oligomeric all-vs-all alignment
   - Supports combined use of -dir with -mm 1
   - Implements intra-directory oligomer all-vs-all alignment
   - Uses upper triangle double loop (ii < jj) to avoid duplicate comparisons and self-comparison

Core functional changes:
1. Removed the incompatibility restriction between -mm 1 and -dir/-dir1/-dir2
   - Original version blocked -mm 1 or -mm 2 from being used with -dir simultaneously
   - Beta branch changed to only block -mm 2 from being used with -dir simultaneously
   - -mm 1 oligomer alignment can now enter batch processing logic

2. New -mm 1 batch mode dispatch logic
   - -dir1: directory query set individually aligned to a fixed target
   - -dir2: fixed query individually aligned to directory target set
   - -dir: intra-directory pairwise all-vs-all alignment
   - Each batch combination still reuses the existing MMalign() main logic

3. New -chainmap mutual exclusion check
   - -chainmap still only allowed with -mm 1
   - Beta branch further prohibits -chainmap from being used with -dir, -dir1, or -dir2 simultaneously
   - Reason: in batch mode, each complex pair may need different chain mappings; a single chainmap file is not suitable for global reuse

Overall conclusion:
The main function of the Usalign-beta branch is to enable oligomer alignment mode (-mm 1) to support batch input, including three directory modes: -dir1, -dir2, and -dir. The implementation approach is conservative, without modifying the MMalign() core algorithm, instead adding loops at the main() dispatch layer to decompose batch jobs into multiple single-pair oligomer alignment executions.
